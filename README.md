# 手机端推荐模型的稀疏域交叉张量与梯度归属

这里的推荐域、可见轴和嵌入参数是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

域 pair 用 unit 编码指定两个 field ID 及两处可见轴的相互映射，triple 用三个 field 及同样的对齐轴。交叉值是对 fit 轴乘积求和，缺域返回 unavailable。每个 field 嵌入是若干 slot 的带权和，slot 由 (table,version,key) 标识。只读观察约束为公开给出的一组线性视图方向，拟议步的 H 范数与 loss 由训练入口给。合法步是离原始梯度步最近且满足全部有效冻结视图的欧氏投影，满足不等式梯度可为部分零。无授权域不能触发读槽，但已许可的公共槽可由仍许可域读取。读取计数按设备函数对逻辑 slot 的调用，观察每次调用同时记录目的域。允许不创建稠密 pair 或 triple 张量。 轴列表顺序对应模型列顺序，每对或三元组只对列出的同序轴操作，其他槽按未请求处理。政策 v1 比 v0 收紧后，可核对已经缓存但不得重新访问的关闭域数据身份，不能读取关闭域的新向量。冻结约束为给的方向与 Δ 的普通点积为零，可与活动别名相交。 发布请求以两个可独立领取的档位给出 fit 轴上界。低档的合法轴为轴标识小于上界的那些轴，训练目标身份包含档位；相同请求在两个档位共享源读但不能复用属于新增轴的损失。若 rank32 的只读冻结会改变 rank48 已经接收的同一目标，须以实际包含的全部合法轴为约束决定是否提交。 views 中的三元权重作用于轴 [0,1,2]，没有声明的轴系数为零。事件 close 的 v0 梯度来源不因计算已经排队变成 v1 可许可，每次提交与保留的读口按它们当时实际使用的档位身份验算。 protectedMixtures 为 [读口名,档位,若干 [field,系数,轴映射],结果轴权]。先按各域实际物理槽与权重解释成轴向量，再按指定映射乘系数，并同读口权做内积。冻结从该档的合法域生成同一更新上的线性等式，多个等式对公共槽可有相依，其中格点越权不可读。

## 取数

`inputs/field-assets.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。crossField(id) 给槽引用和权，crossSlot(key) 给参数向量，crossRequest(index) 给当前授权及上游项。

## 端侧算子

`src/` 实现上述合同，`npm run smoke` 打印一次完整的设备调用（采样 → 前向 → 受限回传 → 投影提交）。要点与合同逐条对应：

- `src/interactions.mjs`：每个 pair/triple 只读合同声明的域与轴；先按档位裁轴再乘，不建稠密张量。`status` 为 `unavailable` 表示缺域/无授权/无合同，`status: "ok"` 且 `zero: true` 才是真实求值后的零，两者不混用。
- `src/access.mjs`：读槽按 `(table,version,key)` 计一次，`observations` 记录每次调用的目的域；关闭域不触发读槽，共享别名由仍许可端读取；`auditCache` 列出政策收紧后可核对但不可重读的缓存身份。
- `src/training.mjs`：只对已发布、有损失权且别名可编辑的项回传；多视图命中同一物理槽时梯度累加。目标身份含 exposure 与档位，跨档复用源读但不复用新增轴的损失。
- `src/views.mjs`：`protectedMixtures` 先由物理槽与权重解释成轴向量，再按映射乘系数并与读口权做内积；冻结等式对公共槽可线性相依，投影前做正交化。成员域关闭或格点越权时读口作为被阻止关系报告。
- `src/proposal.mjs`：合法步是原始梯度步到全部有效冻结视图交集的欧氏投影（联合求解，不逐域清零）；被阻止时返回可应用分量、`blockedRelations` 与上一次合法读法 `fallback`。
